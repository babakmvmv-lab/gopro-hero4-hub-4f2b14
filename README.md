# GoPro Hub

اپ تشخیصی قابل نصب برای آیفون و HERO4. اتصال به شبکه مقصد و تغییر فریمور هنوز پیاده‌سازی نشده‌اند.

## آدرس زنده
https://babakmvmv-lab.github.io/gopro-hero4-hub-4f2b14/

در Safari باز کنید، Share و سپس Add to Home Screen را انتخاب کنید.

## انتشار و به‌روزرسانی
GitHub Pages از ریشه شاخه main منتشر می‌شود. تغییرات جدید در main پس از تکمیل انتشار در دسترس قرار می‌گیرد. در هر تغییر فایل‌های اپ، مقدار CACHE در sw.js را نیز افزایش دهید، مثلاً از v1 به v2. اپ هنگام دسترسی به اینترنت نسخه جدید را بررسی کرده و در صورت آماده بودن دکمه به‌روزرسانی نمایش می‌دهد. وای‌فای دوربین ممکن است اینترنت نداشته باشد؛ برای به‌روزرسانی موقتاً به اینترنت وصل شوید.

این پروژه هنوز روی دوربین واقعی آزمایش نشده است.
