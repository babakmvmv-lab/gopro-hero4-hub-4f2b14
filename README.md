# GoPro Hub

اپ تشخیصی قابل نصب (PWA) برای iPhone و HERO4. تغییر فریمور، اتصال به شبکه مقصد و ارتباط خودکار با دوربین هنوز پیاده‌سازی نشده‌اند.

## انتشار
1. یک مخزن جدید GitHub بسازید و همه فایل‌های این پوشه، از جمله `.github/workflows/pages.yml` را به شاخه `main` منتقل کنید.
2. در Settings → Pages بخش Build and deployment گزینه **GitHub Actions** را انتخاب کنید. اجازه اجرای Actions و Pages باید برای مخزن فعال باشد.
3. پس از موفقیت workflow آدرس معمولاً `https://USERNAME.github.io/REPOSITORY/` است؛ آدرس دقیق در خروجی workflow/Settings → Pages دیده می‌شود.
4. در Safari آیفون آدرس HTTPS را باز کنید، Share → Add to Home Screen را بزنید.

پس از push به main، workflow اپ را مجدداً منتشر می‌کند. مرورگر تنها پس از اتصال به اینترنت و بررسی نسخه جدید آن را دریافت می‌کند. اگر نسخه جدید در انتظار باشد دکمه دریافت نمایش داده می‌شود. با تغییر فایل‌های کش‌شده مقدار CACHE در `sw.js` را نیز تغییر دهید (مثلاً v1 به v2). در شبکه دوربین ممکن است دسترسی به اینترنت برای به‌روزرسانی وجود نداشته باشد. نصب آفلاین وابسته به پشتیبانی مرورگر و بارگذاری اولیه موفق است.

تست محلی: `python3 -m http.server 8000`؛ Service worker به HTTPS یا localhost نیاز دارد. پیش‌نمایش فایل داخل iframe و اجرای آن روی کامپیوتر به معنی تست ارتباط با دوربین در آیفون نیست. آدرس وضعیت دوربین یک لینک HTTP محلی است و موفقیت آن وابسته به شبکه، دوربین و رفتار iOS است.
